# Netflix_Data_Analysis

The Netflix Data Analysis Project aims to explore and visualize trends in movies and TV shows available on Netflix. Using Python and data analytics libraries such as Pandas, Matplotlib, and Seaborn, this project performs detailed exploratory data analysis (EDA) to uncover insights about the streaming platform’s content distribution, genres, ratings, and yearly trends.

The dataset includes information such as title, type, director, cast, country, release year, rating, and genre. The analysis helps answer key questions like:

What is the ratio of Movies to TV Shows on Netflix?

Which countries produce the most Netflix titles?

What are the most common genres available?

How has Netflix’s content grown over the years?

What ratings are most frequent among Netflix titles?

Through visualizations and trend analysis, this project provides a data-driven understanding of Netflix’s global content strategy and viewing diversity. It demonstrates practical skills in data cleaning, data visualization, and insight generation using Python.

Data preprocessing and cleaning using Pandas

Exploratory data analysis (EDA)

Data visualization using Matplotlib and Seaborn
